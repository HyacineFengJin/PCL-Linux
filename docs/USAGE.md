# 使用指南

PCL Linux 当前用于启动已经安装好的 Minecraft 游戏版本。首次运行前，请按[README](../README.md#构建与运行)完成构建。

## 选择游戏目录

1. 打开「设置」。
2. 在「Minecraft 数据目录」中填写游戏目录路径。该目录应包含 `versions`、`libraries` 和 `assets`。
3. 点击「保存设置」。
4. 回到「启动」，点击「版本选择」，选择要运行的版本。可以输入版本名称进行搜索。

如果没有显示版本，请检查目录是否正确，并在版本选择窗口点击「重新扫描」。

## 启动游戏

填写离线玩家名称，选好版本后点击「启动游戏」。启动器会先检查 Java 和依赖，再运行游戏。

离线身份适用于单人游戏和允许离线身份的服务器。[Microsoft 正版登录](AUTHENTICATION.md)暂未开放。

Java 会根据游戏要求自动选择。使用系统安装的 Java 时，确保所需版本可通过 `PATH`、`JAVA_HOME` 或 `/usr/lib/jvm` 找到。Forge / NeoForge 实例需要匹配对应的 Java 主版本。

## 调整内存

- 在「设置 → 默认最大内存」中设置所有版本的默认上限，点击「保存设置」。
- 在「版本设置 → 此版本最大内存」中设置单个版本的上限，点击「保存」。该值会覆盖默认设置。

界面以 GiB 为单位。最大内存是 Java 堆的上限，不代表游戏启动时会立即占用全部额度。

## 启动遇到问题

打开「版本设置」，点击「检查启动环境」查看 Java、游戏目录及依赖检查结果。检查通过后仍无法进入游戏时，可以打开「工具 → 游戏日志」查看最近一次启动的输出。

当前版本不会自动下载缺少的文件。缺少游戏依赖时，需要先补全安装；已有的 Windows 游戏目录也可能需要对应的 Linux 原生库。

在游戏内使用正常退出操作。启动器中的「结束进程」会立即结束游戏，未保存的进度可能丢失。

## 桌面应用入口

在项目目录运行：

```sh
./install-desktop.sh
```

之后可以从系统应用菜单打开「PCL Linux（实验版）」。入口引用项目内的程序，移动项目目录后需要重新安装入口。

移除入口：

```sh
./uninstall-desktop.sh
```

此操作只移除应用菜单入口，保留程序和游戏文件。
