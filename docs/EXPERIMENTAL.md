# 实验功能

在 **工具 → 百宝箱 → 实验功能** 打开以下功能。它们目前均为 **Experimental / 实验性**，使用启动器现有的卡片、下拉框和确认弹窗。

## 插件系统 · 0.6

导入 JSON 声明或 `.pclext` JSON 包，检查名称、发布者及请求权限，再选择授权并安装。发布者身份未经验证。

支持的权限：

- 显示带来源标识的纯文本功能卡片。
- 切换到启动、实例选择、下载、工具或设置页面。
- 展示当前实例的游戏版本、加载器、模组数量和隔离状态。

可以撤销权限、禁用插件、重新授权，或用安全模式暂停全部卡片。声明和授权保存在本地；更新声明内容需要再次确认。撤销必需权限会暂停插件，撤销可选权限会停用相应按钮。

这是数据型插件系统，不执行插件代码，也不兼容 PCL N / Nex 插件。实例摘要不包含目录、账号或登录令牌。示例声明见 [Instance Compass](../experimental/extensions/examples/instance-compass.json)。

## AI 模组制作器 · 0.4

1. 设置模组 ID、名称、简介和物品。
2. 配置中英文名称、颜色、堆叠上限及使用原版材料的无序配方。
3. 使用默认的本地模板方式生成 **Fabric 1.21.1 源码工程**。
4. 在任务记录中选择工程和文件，编辑 Java 或受支持的资源文本。
5. 查看修改预览，确认后创建新的源码副本。

手写修改会自动保护，也可以单独保护文件。更新模板会保留受保护内容；历史副本可以恢复到另一个新副本，原工程仍保留。可从界面打开工程目录，继续使用自己的编辑器和构建工具。

当前模板支持普通物品、贴图和配方，最多 16 个物品。方块、实体、复杂玩法和通用工具行为尚不支持。生成工程不代表已成功编译或能在游戏中运行；启动器不会自动执行工程构建脚本。

## 模组搬运器 · 0.5.1

1. 选择模组**源码目录**，导入支持的文本文件。
2. 选择目标版本，声明自己的源码修改权限；测试版目标需要接受测试版状态。
3. 手动选择允许补丁修改的文件，再进行风险分析。
4. 查看风险与迁移计划，可预览受支持的转换方案或提出文本修改。
5. 核对补丁后，确认生成导入文本的新副本。

当前内置转换方案包括：Fabric 身份字段映射到已有的 NeoForge 元数据模板，以及限定的 Fabric/Yarn **1.20.6 → 1.21 Identifier** API 改写。无法处理的语法、缺少模板、版本不匹配和其他迁移事项会保留说明。元数据修改不意味着入口、依赖和游戏行为已经完成迁移。

不支持直接转换 JAR，也不是通用一键搬运。目标目录项来自随工具提供的离线快照，不是完整兼容性目录。共享引擎当前只接受约 30 KB 的导入文本快照；超过限制会拒绝导入。补丁结果只包含明确导入的文本，不会复制被跳过的二进制资源或自动构建。

## 共享 Pi Agent 引擎 · v7

制作器与搬运器共用本地任务引擎，支持两个独立任务同时运行。工程副本和任务记录保存在项目的 `.pcl-rust/experimental/`，关闭启动器时会停止活动任务。

默认使用本地模板和静态分析。展开「共享 Pi Agent 引擎」可配置当前包支持的 DeepSeek 接口密钥，再显式选择真实 AI 方式。密钥仅用于本次会话，重开启动器后需要重新配置。真实 AI 接口尚未实测，调用可能产生接口费用；模型输出需自行核对。模型不能替用户批准补丁，也不会获得游戏目录写入权限。

实验功能需要 **Node.js 22.19+、Python 3.11+**。`build-native.sh` 会按锁文件安装 Pi 依赖；Pi SDK 固定为 `1.0.4`。
