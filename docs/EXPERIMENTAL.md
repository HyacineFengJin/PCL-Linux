# 实验功能

在 **工具** 的侧栏分别打开 **插件管理、模组项目、模组制作、一键搬运**。共享 Pi 配置位于独立的 **AI 管理** 页面。它们目前均为 **Experimental / 实验性**，使用启动器现有的卡片、下拉框和确认弹窗。

插件系统分为「插件管理」和「插件市场」；市场当前仅为留白页面，尚未开放。

## 插件系统 · 0.6.1

导入 JSON 声明或 `.pclext` JSON 包，检查名称、发布者及请求权限，再选择授权并安装。发布者身份未经验证。

支持的权限：

- 显示带来源标识的纯文本功能卡片。
- 切换到启动、实例选择、下载、工具或设置页面。
- 展示当前实例的游戏版本、加载器、模组数量和隔离状态。

可以撤销权限、禁用插件、重新授权，或用安全模式暂停全部卡片。声明和授权保存在本地；更新声明内容需要再次确认。撤销必需权限会暂停插件，撤销可选权限会停用相应按钮。

这是数据型插件系统，不执行插件代码。实例摘要不包含目录、账号或登录令牌。示例声明见 [Instance Compass](../experimental/extensions/examples/instance-compass.json)。

同一导入入口可选择 PCL N 或 Nex 插件的 **`plugin.json`**，打开只读兼容报告，查看声明的程序集入口、服务、权限、插件依赖及 Mixin 配置。报告不会安装或执行插件，不授予权限，也不验证签名、完整上游格式、依赖是否已安装或程序集实际行为。N 的 Avalonia/DirectInject 页面以及 Nex 的 PCL.Core/Mixin 环境尚未适配；`.pnp`、`.pclx` 包不能直接导入。

提供独立的 [开发验证工具](../experimental/extensions/compat/README.md)：用 N SDK 0.2.5 原始 Hello 源码验证命令及双语设置页描述接口。该工具不随启动器启动，不表示完整 N 插件已兼容。

## AI 模组制作器 · 0.5

1. 设置模组 ID、名称、简介和物品。
2. 配置中英文名称、颜色、堆叠上限及使用原版材料的无序配方。
3. 使用默认的本地模板方式生成 **Fabric 1.21.1 源码工程**。
4. 在任务记录中选择工程和文件，编辑 Java 或受支持的资源文本。
5. 查看修改预览，确认后创建新的源码副本。

手写修改会自动保护，也可以单独保护文件。更新模板会保留受保护内容；历史副本可以恢复到另一个新副本，原工程仍保留。可从界面打开工程目录，继续使用自己的编辑器和构建工具。

普通模板修订和源码编辑后的模板更新使用同一套文件保护检查，每次创建副本都会更新保护记录。预览会列出保留的受保护文件和未应用的模板变更；相关源码与新资源是否一致仍需自行核对。删除或改名物品、恢复较早副本时，预览会提示被移除的物品 ID；源码恢复不会恢复游戏存档。

自动保护适用于制作器中经过预览确认的修改。模板文件或受保护文件若被外部编辑器改动，制作器会拒绝不一致的模板或保护记录，保留原文件；当前不支持自动导入这些外部修改。可以继续在外部编辑器中维护，也可以在未改动的历史副本上重新提交源码修改。

当前模板支持普通物品、贴图和配方，最多 16 个物品。复杂玩法不受模板字段表达能力的限制：源码编辑可修改已有 Java 与受支持的资源文本，AI 续作还可提出新增 Java 类和资源文本，但具体 API、入口注册和行为正确性仍需开发者核对。构建脚本、保护元数据和二进制资源不能通过文本补丁修改。生成源码不代表已成功编译或能在游戏中运行；启动器不会自动执行工程构建脚本。

### 模组项目

在 **模组项目** 选择已结束任务的源码产物，填写项目名称、项目说明和版本说明，即可保存项目。可以登记制作器工程或搬运器产生的文本副本，随后追加版本、选择历史版本、编辑说明或归档项目。归档可以撤销，不会删除源码。项目版本保存产物引用和内容指纹，不会移动或改写原工程；任务目录与记录需一并保留。

项目说明适合记录玩法要求、设计决定和手写内容的约束。切换项目或进入 AI 管理时，未保存的说明保留在当前启动器会话中；重启后只有已保存的说明仍在。保存时若项目已变化，会拒绝覆盖并保留草稿，刷新后可明确选择用当前草稿覆盖最新说明。

打开制作器历史版本会恢复该版本的模板参数和文件选择；打开搬运版本会在搬运器中只读查看，避免将旧导入快照的补丁误认为对该结果的续作；继续迁移需将结果源码目录导入新任务并重新授权文件。**AI 续作** 使用 AI 管理中已经保存并选中的预设，复制所选制作器版本到新任务，将项目说明、需求和源码清单交给共享 Pi 引擎。模型可读取现有源码、提出复杂 Java 与资源修改，由用户审阅后生成新副本。续作不会替换旧版本，也不会自动将结果登记为项目版本；确认后可回到项目页登记新的任务产物。

项目最多 128 个，每项目最多 128 个源码版本；项目说明最多 8192 字符。源码快照沿用共享审阅限制（最多 300 个文件、总计 256 KB），不是大型外部工程的通用导入器。源码文件若被外部改动或缺失，续作会拒绝使用不一致的版本。

界面分别显示源码版本已登记、模组编译未运行、游戏验证未运行。当前不支持启动测试游戏、模组组合测试、通用完整移植或从插件直接执行源码修改；搬运产物可以统一管理，但 AI 续作目前只接受制作器工程。

## 模组搬运器 · 0.5.1

1. 选择模组**源码目录**，导入支持的文本文件。
2. 选择目标版本，声明自己的源码修改权限；测试版目标需要接受测试版状态。
3. 手动选择允许补丁修改的文件，再进行风险分析。
4. 查看风险与迁移计划，可预览受支持的转换方案或提出文本修改。
5. 核对补丁后，确认生成导入文本的新副本。

当前内置转换方案包括：Fabric 身份字段映射到已有的 NeoForge 元数据模板，以及限定的 Fabric/Yarn **1.20.6 → 1.21 Identifier** API 改写。无法处理的语法、缺少模板、版本不匹配和其他迁移事项会保留说明。元数据修改不意味着入口、依赖和游戏行为已经完成迁移。

不支持直接转换 JAR，也不是通用一键搬运。目标目录项来自随工具提供的离线快照，不是完整兼容性目录。共享引擎当前只接受约 30 KB 的导入文本快照；超过限制会拒绝导入。补丁结果只包含明确导入的文本，不会复制被跳过的二进制资源或自动构建。

## 共享 Pi Agent 引擎 · v7

制作器与搬运器共用本地任务引擎，支持两个独立任务同时运行。工程副本和任务记录保存在项目的 `.pcl-rust/experimental/`，关闭启动器时会停止活动任务。

默认使用本地模板和静态分析。在 **工具 → AI 管理** 选择提供商和模型、填写 API Key、预设名称并点击「保存预设」，再到制作器或搬运器显式选择真实 AI 方式；调用时自动启动，也可在 AI 管理页点击「启动」。此页面配置的是两个工具共用的引擎，不是独立聊天窗口。

内置提供商来自随包固定的 Pi 模型目录，包括 OpenAI、Anthropic、DeepSeek、OpenRouter、Groq、Mistral 等 API Key 提供商。不是 DeepSeek 专用引擎；列表不在线刷新，模型是否开放以及账号权限由提供商决定。当前使用 API Key，不导入 Pi CLI 的登录凭据；OAuth、云账号认证和 Google 原生协议尚未接入。

选择「自定义提供商」可填写模型 ID、基础地址和上下文窗口，支持 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 协议，也可连接本地 HTTP 服务。基础地址不含具体请求路径：OpenAI 兼容服务通常使用 `https://example.com/v1`，Anthropic 兼容服务通常使用 `https://example.com`。无须认证的本地接口可留空密钥；需要认证的接口应填写对应密钥。自定义模型默认不启用推理专用参数。选择新的提供商会清空密钥输入；编辑同一预设且未改变提供商或接口时，留空可保留已保存密钥。

预设保存提供商、模型、思考强度、密钥与高级限制，可新建、切换、修改和删除。密钥输入使用密码遮罩；密钥保存在本地私有文件 `.pcl-rust/experimental/ai-presets.json`（权限 0600），不会返回到界面或进入任务记录。停止引擎会取消活动 AI 任务，保留预设；重开启动器后预设仍在。运行中的任务保留提交时的配置，预设修改用于后续任务。

「高级设置」默认折叠，可调整每个预设的模型调用次数、工具调用次数、时长、输出量和估算费用。默认每任务 32 次模型调用、128 次工具调用、15 分钟，单次输出最多 8192 tokens；模型自身的输出上限仍生效。有目录价格或填写自定义价格时，默认使用 $5 的估算额度；未填写自定义价格时不执行费用估算限制，其余限制仍生效。估算不是实际账单。真实 AI 服务尚未进行在线验证，调用可能产生接口费用；模型输出需自行核对。模型不能替用户批准补丁，也不会获得游戏目录写入权限。

实验功能需要 **Node.js 22.19+、Python 3.11+**。`build-native.sh` 会按锁文件安装 Pi 依赖；Pi SDK 固定为 `1.0.4`。
